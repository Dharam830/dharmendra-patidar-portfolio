# Dharmendra Patidar — Theme 4: Professional Corporate

Responsive static portfolio built using plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — corporate layout and responsive styling
- `script.js` — mobile navigation, reveal animations and current year

## Run
Open `index.html` in a browser. No dependencies or build step are required.

## Before publishing
- Replace the resume download filename with the correct resume file, and include that file in the website folder.
- Optionally add LinkedIn/GitHub links and a profile photo.
- Verify project details and technical skills before publishing.

Can be deployed to GitHub Pages, Netlify, Vercel static hosting, or any web server.
